# 注册功能使用说明

## 📋 功能概述

前端项目已完整集成用户注册功能，与后端 `/api/user/register` 接口对接。

---

## 🔗 接口信息

### 后端接口
- **URL**: `POST /api/user/register`
- **完整路径**: `http://127.0.0.1:8000/api/user/register`
- **请求参数**:
  ```json
  {
    "username": "用户名",
    "password": "密码"
  }
  ```
- **成功响应**:
  ```json
  {
    "code": 200,
    "message": "success",
    "data": {
      "token": "认证令牌",
      "userInfo": {
        "id": 1,
        "username": "用户名",
        "nickname": null,
        "bio": null,
        "avatar": null,
        "gender": null,
        "phone": null
      }
    }
  }
  ```
- **失败响应**:
  ```json
  {
    "code": 400,
    "message": "用户名已存在"
  }
  ```

## 🚀 使用流程

### 方式一：从登录页进入
1. 打开应用，进入登录页面 `/login`
2. 点击"还没有账号？**去注册**"链接
3. 跳转到注册页面 `/register`
4. 填写用户名和密码
5. 点击"注册"按钮
6. 注册成功后自动跳转到首页 `/home`

### 方式二：直接访问
1. 浏览器访问 `http://localhost:5173/register`
2. 填写注册表单
3. 提交注册
4. 自动登录并跳转首页

## 📝 表单验证规则

### 用户名
- **必填**: ✅
- **最小长度**: 无限制
- **最大长度**: 无限制

### 密码
- **必填**: ✅
- **最小长度**: 无限制
- **确认密码**: 必须与密码一致

### 验证逻辑
```javascript
// 确认密码验证器
const validatePassword = () => {
  return password.value === confirmPassword.value;
};
```

## 🔐 注册成功后的行为

1. **自动登录**: 注册成功后自动登录
2. **保存 Token**: Token 保存到 localStorage
3. **保存用户信息**: userInfo 保存到 Pinia store
4. **设置登录状态**: `isLogin = true`
5. **跳转首页**: 自动跳转到 `/home`

---

## ⚠️ 注意事项

### 1. 用户名唯一性
- 后端会检查用户名是否已存在
- 如果已存在，返回错误："用户名已存在"
- 前端会显示相应的错误提示

### 2. 密码安全
- 密码在后端会自动加密存储（bcrypt）
- 前端传输使用明文（建议生产环境使用 HTTPS）

### 3. 错误处理
```javascript
// 捕获异常并显示友好提示
catch (error) {
  showToast({
    type: 'fail',
    message: '注册失败，请稍后再试'
  });
}
```
